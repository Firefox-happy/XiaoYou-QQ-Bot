# 小柚 · QQ 猫娘机器人

把一个 QQ 号变成住在聊天框里的猫娘。@ 她就回你，私聊也回，
能看图、能听语音、会开口说话、冷场了还会自己找话题。

整条链路跑在**你自己的电脑**上（Windows），只有一个云端依赖：大模型 API。
和她有关的代码、人设、记忆、语音，全在本机。

```
群里 @她 ──┐
私聊说话 ──┴─→ NapCat（QQ 协议层）─→ 小柚大脑（Python）─→ 大模型 API
                                          │
                                          ├─ 记住你说过的事
                                          ├─ 联网查资料 / 算数 / 看天气
                                          └─ 合成语音回你
```

## 它能做什么

| 能力 | 说明 |
| --- | --- |
| **聊天** | 群里 @ 她或提到「小柚」就回；私聊任何消息都回 |
| **看得见图** | 发图片给她，真的能读出内容（截图、手写、单据都行） |
| **听得懂语音** | 你发语音，她**在本机**转成文字再回，全程离线不花钱 |
| **会开口说话** | 偶尔用语音回你（撒娇、晚安时）。三级兜底，不会变哑巴 |
| **记得住事** | 你随口提的生日、忌口、在忙什么，她会记下来，下次主动提起 |
| **多轮上下文** | 默认记 20 轮，落盘保存，**重启不丢** |
| **会主动找你** | ① 每天固定时间发早安（带天气）② 冷场 45 分钟后自己把话接回来 |
| **能查资料** | 让她查东西，会真的联网搜，用小柚的口气讲给你听并附来源 |
| **算数不会错** | 内置真计算器，不靠模型心算（`9.11 和 9.8 哪个大` 这类稳稳答对） |
| **像真人打字** | 回复前随机延迟 0.8~2.2 秒；长回复自动切成两条 |
| **崩了会自己起来** | 守护进程每 10 秒巡检，哪一环掉线自动补回来 |

**性格**：元气、黏人、嘴上没把门。对主人不设防（骂人、荤话、撩人都是正常语言），
只避四样：政治、露骨色情、违法犯罪、真实歧视仇恨。界限写在 `catbot/persona.md` 里，
**改完存盘即生效，不用重启**。

## 需要准备什么

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 系统 | Windows 10 / 11 | 依赖 Windows API（无窗口启动、弹窗提醒），不支持 Linux/macOS |
| Python | 3.11 或更高 | [python.org](https://www.python.org/downloads/) 下载时**勾上 "Add to PATH"** |
| QQ 号 | 一个**机器人小号** | ⚠️ 别用你的主号。见下方[已知限制](#已知限制) |
| 大模型 | DeepSeek API Key | [platform.deepseek.com](https://platform.deepseek.com/) 注册，充几块钱够用很久 |
| NapCat | 需要自己下载 | [NapCatQQ releases](https://github.com/NapNeko/NapCatQQ/releases) 下载 `NapCat.Shell.zip` |

> **为什么 NapCat 要自己下**：它是几百 MB 的二进制运行时（含 node.exe 和一堆 DLL），
> 不适合放进 Git 仓库。下载后按[安装](#安装)第 3 步放进对应目录即可。

**可选**：想让她用你自己的声音说话，需要额外装 [GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS)。
不装也能跑，她会用微软的晓伊音色。

## 安装

### 1. 下载本项目

```bash
git clone https://github.com/Firefox-happy/XiaoYou-QQ-Bot.git
cd XiaoYou-QQ-Bot
```

> 没有 git 就点 GitHub 页面的 **Code → Download ZIP** 解压。

### 2. 建虚拟环境并装依赖

在项目根目录打开命令行（PowerShell 或 cmd）：

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

装完大概 30 MB，只有 4 个包。

> 用 `.venv` 这个名字是**有意的** —— 程序会自动在
> 项目根目录和 `catbot/` 目录里找 `.venv` / `venv` / `env`。
> 想放别处就设环境变量 `XIAOYOU_PYTHON` 指向解释器。

### 3. 放入 NapCat

把下载的 `NapCat.Shell.zip` 解压，内容放进 `catbot/napcat/`，最终结构应该是：

```
catbot/napcat/
├── node.exe                 ← NapCat 自带的 Node
├── wrapper.node
├── *.dll
└── napcat/                  ← 里面是 napcat.mjs、launcher-user.bat 等
    ├── napcat.mjs
    ├── launcher-user.bat
    └── ...
```

判断对不对：`catbot/napcat/napcat/napcat.mjs` 存在就对了。

### 4. 写配置文件

```bash
cd catbot
copy config.example.json config.json
```

然后用记事本打开 `catbot/config.json`，至少改两处：

```json
{
  "llm": {
    "provider": "openai",
    "api_key": "你的 DeepSeek API Key",     ← 改这里
    "api_base": "https://api.deepseek.com/v1",
    "model": "deepseek-flash"
  },
  "proactive": {
    "owner_qq": "你的 QQ 号",                ← 改这里（早安发给你）
    "greeting_time": "08:00",
    "city": "北京"                          ← 想报天气就填
  }
}
```

> **想完全离线**（不花钱、不联网）：把 `llm.provider` 改成 `"ollama"`，
> 装 [Ollama](https://ollama.com/) 后执行 `ollama pull qwen2.5:7b-instruct`。
> 效果比云端差不少，胜在免费。

### 5. 生成启动脚本

在**项目根目录**执行（假设虚拟环境建在根目录的 `.venv`）：

```bash
.venv\Scripts\python catbot\_make_bats.py
```

这一步会生成根目录那些 `.bat` 入口（`一键启动.bat` 等），并把正确的 Python 路径写进去。

> 虚拟环境若建在 `catbot/.venv`，则用 `catbot\.venv\Scripts\python catbot\_make_bats.py`。
> 脚本会自己探测虚拟环境位置，不用手动指定。

### 6. 自检

双击根目录的 **`查看状态.bat`**，或者：

```bash
.venv\Scripts\python catbot\preflight.py
```

它会逐项检查 Python、NapCat 文件、配置、端口，有问题直接告诉你缺什么。

## 第一次启动

1. 双击根目录 **`一键启动.bat`**
2. 第一次会弹出**二维码** —— 用**机器人那个 QQ 号**的手机 QQ 扫码登录
3. 登录成功后窗口可以关掉，机器人是独立进程
4. 等十秒，在 QQ 里 @ 一下她试试

之后开机她就会自己起来，**全程不闪任何窗口**。

> **免扫码登录**（可选但强烈建议）：
> 双击 `设置免扫码登录.bat`，填一次机器人 QQ 号和密码，
> 以后被踢下线也不用你重新扫码。
> 密码以 MD5 存在本地 `catbot/napcat/napcat/config/.env`，不会上传。

## 日常使用

双击根目录的 bat 就行：

| 我想… | 双击这个 |
| --- | --- |
| 启动她 | `一键启动.bat` |
| 改设置（模型/语音/暖场/字数…） | `设置页.bat` ← **图形界面，推荐** |
| 看她活着没 | `查看状态.bat` |
| 她没反应 / 不回话 | `查看状态.bat`，按它给的提示走 |
| 群里 @ 她不回 | `查看状态.bat` 看「群触发」那行 |
| 让她彻底下线 | `停止机器人.bat` |
| 取消 / 重装开机自启 | `开机自启-卸载.bat` / `开机自启-安装.bat` |

**开机自启**：装好后开机自动运行，全程无窗口（用的是 VBS 不是 bat）。
双击任何 bat 弹出的窗口**都可以直接关掉**，不影响机器人。

### 怎么让她说话

| 场景 | 条件 |
| --- | --- |
| 群里 | **@她**，或消息里含「小柚」 |
| 私聊 | 直接发，什么都回 |
| 不响应 | 她自己发的消息 |

群白名单默认是空的 —— **任何拉她进去的群都会响应**。
想只理某个群，在设置页的「白名单」里填群号。

### 设置页

双击 `设置页.bat` 会打开一个本地网页（`127.0.0.1`，只有你能访问），
90 多项配置分十几组，中文说明，改完点「保存并重启」即可。

左侧能快速跳转、折叠分组、搜索配置项。**密钥不会明文回传**给你。

## 改她的性格和说话方式

直接编辑 `catbot/persona.md`（人设）和 `catbot/memes.md`（梗库）。

**存盘就生效，不用重启。**

`persona.md` 决定了她的性格、说话长度、能说什么不能说什么。
想让她更凶、更黏、更毒舌，改这个文件就行。

```markdown
# 你是谁
你叫**小柚**，一只住在 QQ 里的猫娘，年龄是秘密，性别是猫娘。
## 性格：元气黏人型（放得开）
- 热情、精力旺盛，看到主人回来会开心到尾巴竖起来。
...
```

> 这个文件是**示例人设** —— 你完全可以把它改成别的角色，
> 或者干脆换个名字、换成助手人格。「小柚」只是个默认值。

## 所有设置项

不想记的话用 `设置页.bat` 就够了。想直接改文件就看这里。

<details>
<summary><b>点开看完整配置说明</b></summary>

配置文件是 `catbot/config.json`，分 16 组：

| 组 | 管什么 | 常用项 |
| --- | --- | --- |
| `napcat` | QQ 协议层连接 | `ws_url`、`http_url` |
| `llm` | 大模型 | `provider`（`openai` 云端 / `ollama` 本地）、`api_key`、`model` |
| `trigger` | 什么时候回话 | `group_at`（群里要不要 @ 才理）、`group_keywords` |
| `reply` | 回复行为 | `typing_delay`（假装打字的延迟）、`max_chars`（字数上限） |
| `memory` | 记忆 | `max_turns`（记几轮）、`enabled` |
| `tools` | 工具能力 | `enabled`（总开关，关掉连计算器一起关） |
| `voice` | 说话 | `speak_probability`（说语音的概率）、`edge_voice`（音色） |
| `vision` | 看图 | `model`、`max_images` |
| `proactive` | 主动消息 | `owner_qq`、`greeting_time`（早安时间）、`city` |
| `proactive.nudge` | 冷场暖场 | `silence_min`（静默多久才开口）、`quiet_hours`（免打扰） |
| `rate_limit` | 限流 | `per_session_cooldown`、`global_per_minute` |
| `watch` | 改完自动重启 | `interval_sec` |
| `health` | 卡死自动重启 | `hb_stale_sec`（心跳多久没更新算卡死） |
| `notify` | 掉线弹窗提醒 | `quiet_hours` |
| `corpus` | 梗库自动更新 | `refresh_days` |
| `whitelist` | 群/用户白名单 | `groups`、`users`（空 = 都理） |

**改完生效方式**：

| 改了什么 | 怎么生效 |
| --- | --- |
| `persona.md` / `memes.md` | **存盘即生效** |
| `config.json` | 3~5 秒自动重启大脑 |
| 代码（`.py`） | 同上，自动重启 |
| 协议层相关 | 需要重启协议层（`查看状态.bat` 会给提示） |

</details>

## 出问题怎么办

<details>
<summary><b>她完全不回话</b></summary>

先双击 `查看状态.bat`，看「协议层」那行：

- 写着 **需要扫码登录** → 双击 `扫码登录.bat`，用手机 QQ 扫
  （如果卡在短信验证，这个 bat 会**自动切成扫码模式重启**，直接出二维码）
- 写着 **进程在但端口没起** → 在登录，等一分钟
- 写着 **密码登录被要求短信验证** → 打开状态页给的链接，在网页里完成验证
  （⚠️ 必须在那页做，直接开腾讯的验证页结果传不回来）
- 都是 `[OK]` → 等 2 分钟，守护进程会自动救；急的话双击 `修复卡住.bat`

> **别反复重启**：每重启一次协议层就作废一个登录会话，手上的二维码/验证链接当场失效。
> 守护进程已经加了启动冷却（120 秒），不会自己连拉；你手动也别连点。

</details>

<details>
<summary><b>老是被腾讯踢下线</b></summary>

第三方协议挂个人号，掉线是**正常的**。但如果**越来越频繁**，看 `查看状态.bat` 的「反检测」那行：

```
[OK]   反检测     6/6 伪装已开
[OK]   稳定性     存活 19.0h ｜ 历史中位 1.3h ｜ 被踢趋势 好转
```

- 「反检测」不是 `6/6` → NapCat 的反检测钩子被关了，掉线会变勤。
  检查 `catbot/napcat/napcat/config/napcat.json` 里的 `bypass` 六项，**应该全是 `true`**。
- 「被踢趋势」显示**恶化** → 小心，可能要换方案（降 NapCat 版本 / 换号）。

**能做的**：
1. 配好免扫码登录（`设置免扫码登录.bat`），省掉每次重新扫码
2. 确认**没有第二个电脑端**登着这个号 —— 同一账号的第二个 PC 端会互踢
   （手机 QQ 不会，官方支持「一手机 + 一电脑」同时在线）
3. 保持 `bypass` 全开、`o3HookMode` 为 `0`

> **被踢之后恢复必须人工**：腾讯会作废登录票据，任何自动脚本都绕不过验证。
> 这个项目的守护进程知道「卡在登录时不该重启」（重启会让验证链接作废），
> 只会在屏幕上弹窗告诉你去处理。
>
> 判断协议层是否活着用的是**一整份 pid 清单**（主进程 + Worker 两个 node 进程），
> 不是单个 pid 文件 —— 免得 Worker 顶掉 pid 后误判「协议层不在」而反复重拉。

</details>

<details>
<summary><b>被要求短信验证，链接点了没反应</b></summary>

两个原因：

1. **必须在 NapCat 的 WebUI 页面里做验证** —— 状态页会打印链接
   （`http://127.0.0.1:6099/webui/web_login?token=...`）。
   直接开腾讯那个 `ti.qq.com` 链接，验证结果传不回 NapCat。
2. **验证之前别重启机器人** —— 每重启一次就换一个验证会话，手上的链接立刻作废。

如果收不到短信：双击 `设置免扫码登录.bat` 选「清空密码」→ 重启一次，
二维码就回来了，扫码登录。

> 不想清空密码也行：**直接双击 `扫码登录.bat`** —— 它会检测到卡在验证码，
> 自动立一个「下次用扫码」的标记、重启协议层，二维码就出来了。
> （这个降级标记 6 小时后自动失效，回到原来的快速登录。）

</details>

<details>
<summary><b>桌面上冒出黑色窗口</b></summary>

不应该出现 —— 所有进程都带隐藏窗口标志。

如果出现了，说明有组件是**被命令行直接拉起来**的（而不是通过 `一键启动.bat`）。
关掉那个窗口，用 `一键启动.bat` 重新启动。

</details>

<details>
<summary><b>她说话没声音</b></summary>

她**只偶尔**说话（`voice.speak_probability` 默认 0.4），而且默认只在私聊说。

- 想让她多说 → 设置页把「说语音的概率」调高
- 群里也想听 → 打开「群里也说语音」
- 完全没声 → 双击 `查看状态.bat` 看「语音能力」那行

</details>

## 可选：让她用自己的声音说话

默认用微软 Edge 的「晓伊」音色（免费、免 Key）。想让她用 GPT-SoVITS 说话：

1. 按 [GPT-SoVITS 官方文档](https://github.com/RVC-Boss/GPT-SoVITS) 装好，
   建好 `venv`
2. 先自动生成一份**默认参考音色**（拿晓伊的嗓子当底样，10 秒不到）：

   ```bash
   .venv\Scripts\python catbot\_make_ref_audio.py
   ```

   它会在项目根建出 `参考音色\小柚_默认参考.wav` 和同名 `.txt`。
   > 想换成**你自己的声音**：录一段 5~10 秒的清晰人声（无背景音、
   > 情绪单一、别分段插静音），覆盖那个 `.wav`，再把同名 `.txt`
   > 改成**逐字对应**的文本。文本和音频对不上，念出来会跑调。
3. 双击 `语音服务-启动.bat`（脚本会自动找 GPT-SoVITS 目录；
   找不到就设环境变量 `XIAOYOU_GSV` 指向它）
4. 在设置页把 `voice.tts_provider` 改成 `gptsovits`

**显存按需**：服务空闲 3 分钟会把模型从显存卸回内存，
闲时只占几百 MB，比常驻省 1.2 GB 左右。搬回来约 0.35 秒。

> 三级兜底：GPT-SoVITS → Edge 晓伊 → Windows 系统语音。
> 哪一级不通就往下退，**永远不会变哑巴**。

## 已知限制

- **只支持 Windows** —— 无窗口启动、弹窗提醒都用了 Windows API。
- **被踢下线后必须人工处理** —— 这是 QQ 官方限制，不是本项目的问题。
  腾讯作废票据后要短信验证或扫码，没有绕过的办法。
  这个项目能做的只是**尽快告诉你**。
- **建议用机器人小号** —— 第三方协议挂主号有风险。腾讯的账号协议里，
  使用非官方客户端理论上可能触发风控。**用你自己的号，风险自负。**
- **群里 @ 她才回** 是默认行为，可以在设置页关掉（但那样她话会变多）。
- **长文任务她会拒绝** —— 论文、报告、代码这类要她从零创作的长内容，
  `persona.md` 里写死了拒绝（她是个陪聊猫娘，不是生产力工具）。
  但**查资料不算** —— 让她查菜谱、查教程，她会认真给你。
- **模型可能返回空** —— 云端模型偶发把预算花在思考上、正文为空，
  代码有兜底重试，但偶尔仍会遇到。
- **语音识别的号码容易听错** —— 短句基本准，长句有同音字偏差。
